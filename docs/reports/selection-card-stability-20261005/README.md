# 划词卡片与学习中心交互验证

划词卡片默认显示「翻译」，切换学习标签和启停朗读时保持位置。学习中心区分「单词与句子」「阅读记录」「学习笔记」，说明内容来源和保留期限。

- 「收藏原文」保存原文与对应译文，可直达「单词与句子」听读和复习。
- 「保存学习笔记」保存原文与讲解要点，可直达「学习笔记」查看和编辑。
- AI 是否参考笔记由「回答时参考学习笔记」控制；关闭后仍可保存和管理笔记。
- 空列表提供开启收藏入口的按钮。中英文 390px 页面均无横向溢出。

最终生产扩展在临时配置的后台 Edge 中通过 16 个专项场景。相关 9 个测试文件共 219 项通过；多语言文件 54 项通过，3 项失败与已有基线一致。类型检查、三个目标构建、用户脚本校验、文档构建和测试归类审计通过。

测试使用确定性的译文、AI 和静音音频夹具；词典使用真实查询管线。这里的证据不代表真实 AI 输出质量或实际听感，也未进行 Firefox 浏览器交互验证。截图仅包含夹具内容；报告不包含本机绝对路径、进程、显示器标识或扩展标识。
