## 修改

- 进度更新时保留取消操作条的挂载位置，只有进入或退出错误提示时才移动操作条。
- 整图翻译遇到 runtime 消息通道断开时自动恢复一次。重试采用新请求 ID，并尽力取消旧请求；保留原取消信号和总超时预算。
