# 官网划词卡片点击朗读验证

日期：2026-10-04。基于已合并的官网排版 PR #784，追加用户要求的点击实际朗读。

## 行为

原文按钮使用英语朗读卡片原文，译文按钮使用中文朗读对应译文；再次点击停止，切换按钮会取消前一段。自动演示仅展示按钮与声波，不调用朗读。重播、恢复自动演示、页面隐藏和组件卸载均清理当前朗读。准备、朗读、结束、不可用及失败均有对应状态，失败可再次点击重试。

使用浏览器 SpeechSynthesis，在用户点击时创建 utterance。声音按语言匹配；声音列表暂为空时交由浏览器按 utterance 的语言处理，不添加外部服务或密钥。取消前移除事件回调，旧朗读的延迟事件不能覆盖新按钮状态；启动及播放超时会清理状态。

## 浏览器证据

在后台的独立 Codex 内置浏览器预览标签页操作，未连接用户日常 Chrome profile 或抢占前台焦点。

- 中文桌面原文、译文点击均收到浏览器原生 `onstart`，展示对应正在朗读状态。原文原生 `onend` 后恢复 idle。
- 手动停止恢复 idle，原文到译文切换后保持译文状态；Enter 也可启动原文朗读。
- 切换官网语言后无遗留朗读状态。英文 320 像素宽度下译文同样收到原生 `onstart`，可手动停止。
- 自动演示的原文与译文动画帧均维持 speech idle，无朗读目标。
- 中文桌面卡片高度始终 530 像素，英文窄屏始终 542 像素，播放/停止不改变页面高度，无横向溢出。
- 控制台未捕获 warn/error。截图及 DOM 状态见同目录证据。

## 边界

测试替身验证控制逻辑；真实浏览器验证依赖原生朗读开始/结束事件，未录制或评价扬声器输出和不同设备的声音质量。浏览器可用声音因系统而异。未执行插件全量回归，未修改插件的朗读服务或参考仓库。
