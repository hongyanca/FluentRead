# X AI 字幕：低音量、漏词与解码取消复核

日期：2026-10-09。追加修复的对照为本任务已提交的 `8e3f5bcc7d2e4bc21569dd383ea18e7cf2b139f6`。这一轮确认了模型以外的音频门控和字幕整理问题；默认 Tiny/Base、q4 精度、码率及模型下载策略没有调整。

## 保留模型已经识别的词

将同一 11 秒、22 词官方参考自然英文样本交给生产完整采集控制器，使用现有分窗策略和实际 q4 WASM 模型。Tiny 的两个窗口为 0–10 秒及 8.8–11 秒。模型结果含短句与片尾，但旧字幕整理最终只剩 19 词、4 个词编辑错误：同窗较短片段仍等待未来确认时被后句覆盖；已经剥离重叠前缀的延续词再次做全文去重，吞掉了前文出现过的合法句尾词。

完整采集现在显式使用 `mode: 'complete'`，允许提交至少 300 ms、两个词或两个 CJK 字符的完整短段；实时模式继续等待原有跨窗确认。跨窗延续直接追加已经提取的新增后缀，仍由前一步去重。使用冻结的实际模型结果回放当前完整控制器，Tiny 最终为 22 词、1 个错误；Base 仍为 22 词、0 个错误。窗口 PCM 摘要一致，时间轴有限、无 spoken 区间重叠且在输入时长内。

这是恢复已经识别的内容，不是重训模型或整体准确率提升证明。原始推理直接使用 Float32 输入，未经过浏览器 PCM16 消息传输；修复后的控制器回放没有追加模型推理。[窗口和最终指标摘要](./full-pipeline/word-preservation-summary.json)保留源码、输入与结果 SHA；音频与完整转写不入仓。

## 保留低音量人声和短尾

旧采集门使用固定 peak/RMS/活动帧门槛。参考语音乘以 0.003 后，RMS 约 0.000603、peak 约 0.003321，完整控制器在调用模型之前报错。实际 Base q4 WASM 对相同低量输入仍得到 22 词、0 个词错误。修复后采集和 Worker 共用一个 PCM16 步长的数字静音契约；RMS 与活动帧比例保留为统计，不再根据整片平均能量拒绝音频。没有追加增益。

另核对了产品的 `encodeVideoAiPcm16Base64` 与 offscreen 的 `decodePcm16Base64`：使用 TypeScript AST 提取原函数，执行实际 PCM16 往返，再进行一次相同参数的 Base q4 WASM 推理；结果仍为 22 词、0 个错误。这包含实际量化，但不包含浏览器消息、采集和 GPU。[PCM16 结果摘要](./full-pipeline/pcm16-lowgain-summary.json)记录编码大小、量化误差、函数与输入 SHA。单次耗时只作观察，不能作为速度或首句等待验收。

受控语音片尾降低音量后，旧逻辑漏掉 9.7–10.4 秒的尾音；新窗口覆盖到 10.4 秒，对齐也保留尾音。另一条公开 X 音频降低音量再追加 60 秒数字静音，旧整片 RMS 门拒绝全部输入；新逻辑完整覆盖前 12 秒声音并跳过后部数字静音。这两组只验证窗口覆盖，没有新增准确率结论。

两个原创弱噪声样例（白噪声及单频音）的实际模型输出，在现有 Worker 清理和完整字幕整理后均没有预览或最终字幕。未追加新过滤器。非零噪声仍可能消耗推理时间，两条样例不能保证所有配乐、底噪或幻觉行为。[音频与非人声摘要](./full-pipeline/quiet-audio-summary.json)保留对照和边界。

## 读取上限与取消后的资源释放

完整采集的原生 fallback 在没有 Content-Length 时先 `arrayBuffer()` 读到 EOF，才检查 48 MiB 上限；取消待解码任务后 AudioContext 和 8 秒计时器仍存活。现在复用有界流式读取，首个越限 chunk 后取消流；原生 AudioContext 使用 16 kHz 解码，取消同时结束等待、关闭 context 并移除计时器和监听器；HTTP 错误或声明大小越限等提前拒绝也会中止底层请求。

生产模块加模拟 Fetch/ReadableStream/AudioContext 的反例复核通过：X MP4 reader 的 32 MiB 与完整 fallback 的 48 MiB 两条流均在 EOF 前取消；待解码取消后无需推进时钟，context 已关闭且无剩余解码期限。提前 HTTP/大小拒绝在尚未取消或失败清理之前也已中止 fetch。原 1.5 秒读取与 8 秒解码预算保持不变。正常 X HLS/MP4 reader 已使用 16 kHz 解码；这里修复的是后续 fallback，尚未测量它在真实 X 上的出现率或识别收益。[资源反例摘要](./full-pipeline/decode-resource-summary.json)明确记录模拟端口范围，不是浏览器或 CDN 验收。
