# 云备份版本兼容与提示布局验证

验证源码：`e78f67d6dd12a251ae16c2324a8584f353ae549e`。本报告及截图为该源码的生产构建证据。

## 解决的问题

- Google Drive v3 缺少 ETag 时，按同一文件 ID、同一版本补取 v2 元数据，并在 v2 更新端点使用 `If-Match`。
- WebDAV 按 GET、DAV:getetag、HEAD 的顺序获取强 ETag。补取的版本标识必须经条件读取及密文核对后才能用于覆盖。
- 服务没有安全写入版本时，仍能读取备份、查看差异并恢复。直接进入恢复确认，不再显示保存、合并、步骤条或返回选择入口。
- 提示与正文之间留出 24px，长文案换行；密钥、地址和自定义内容继续脱敏。七种界面语言均保留本地化提示。

## 证据边界与真实账号复测

这些结果证明受控 HTTP 服务及模拟 Google 响应下的生产扩展流程，不能代替真实坚果云、真实 Google 账号、多设备或商店发布验证。旧 HAR 只覆盖首次创建前读取失败，没有本次再次保存的请求证据。

用新测试包在独立测试配置中分别检查：

1. 初次保存后修改目标语言，再次点击同步；预览应展示具体设置差异，确认保存后回读成功。
2. 另一个测试配置读取同一备份，先核对差异，再恢复，确认设置一致。
3. 取消预览后，本机设置与云端文件均不改变。
4. 预览后另一个配置修改云端文件，原预览应拒绝过期覆盖并要求重新读取。
5. 若真实服务仍没有强版本标识，应显示可恢复提示及差异，不应提供保存或合并；同时检查桌面及窄屏没有挤压或截断。

无需向开发者提供密码、授权令牌或请求鉴权头。若复测仍失败，记录版本、失败步骤与经过脱敏的响应状态即可。
