# 设置中心与 Popup 体验整理

本轮基于 `e9ba03c7`，在 `codex/popup-image-unification-20260930` 分支完成。保留现有 WXT / Vue / TypeScript 架构，没有修改参考项目或引入跨仓库依赖。

## 最终交互

- 侧边栏各组默认展开。普通设置直接在同页分组展示，翻译统计保留“翻译概览 / 模型用量”两个视图；搜索仍能定位具体分组或开关。
- 翻译服务按功能统一分配。配置连接就地打开编辑窗，关闭后保持原位置；服务目录管理未使用及自定义服务，编辑连接不改变网页默认服务。新编辑窗留在设置 UI 内且不锁宿主页面滚动。
- 图片与圈选合并为一个导航入口，网页图片、圈选方式及共享 OCR 管理在同页展示。旧圈选地址仍可打开。各功能的启用状态、服务和模型配置保持独立。
- 总开关统一为文字在左、滑块在右；整行或文字区域可操作，移除重复的“已开启 / 未开启”，通过 `aria-checked` 保留读屏状态。
- 术语库底部直接显示内置词库。预览和添加沿用原流程，不自动打开总开关。
- 译文样式保留可视卡片、四类分组和真实预览，缩小卡片与留白，减少装饰性内框；逐句高亮独立放入“阅读辅助”。
- Popup 默认宽度 340px，简约 330px、紧凑 320px。首屏分为语言、服务、快捷功能，默认四个快捷入口：悬浮、划词、图片、文档。移除网页翻译大按钮、独立视频/圈选入口以及顶部插件总开关；总开关仍在通用设置，暂停时显示提示。
- 图片快捷抽屉以“网页图片 / 圈选区域”两张等高卡呈现，整卡可点击，圈选快捷键清晰展示。详细 OCR 和识别偏好从底部进入。
- 旧 Popup 圈选卡的顺序与可见性迁入图片卡，显式隐藏两个旧入口时仍保持隐藏；视频功能配置未删除。菜单布局和皮肤预览同步收敛。

## 验证范围

- 相关配置、导航、组件、Popup 操作、样式和油猴资源测试通过；布局迁移及导航模型四维覆盖率均为 100%。
- TypeScript/Vue 检查、Chrome、Firefox、userscript 构建及 userscript verifier 通过。多语言资源有独立提交，资源指针与本地文件一致；当前分支尚未推送，不代表远程 CDN 已可下载新资源。
- 在第二块屏幕的隔离 Edge 临时 profile 验证。只操作本次 profile，使用焦点保护 helper，不访问日常配置或真实翻译服务。一次采样因测试进程进入前台而被保护器中止，后续重新运行。
- 设置遍历覆盖 16 页、统计的 2 个视图、桌面及 390/820/1024px 窄屏、深色、搜索定位、服务就地编辑、开关整行/键盘操作、立即关闭保存和跨页同步。结果记录见下方证据。
- Popup 检查默认入口、隐藏 DOM、冷后台唤醒、语言搜索与键盘选择、关闭重开、深色英文，以及图片和圈选开关互不改变。
- 不将扩展页浏览器验证表述为 Firefox 运行时、真实 OCR / AI 提供商或商店安装验证。

## 已知仓库基线

全仓架构检查仍有四项与本轮未修改文件有关的失败：`browserFocusSafety` 的旧划词路由断言、`contentTrustBoundary` 的旧滚轮模板断言、视频 runtime 行数上限（1909 / 1887）、七个分享卡片及摘录模块缺少覆盖率登记。这些相关文件与基线 `e9ba03c7` 的 diff 为空。本轮曾因新增文案触发的油猴语言资源过期错误已通过重新生成和固定提交解决，相关测试及构建已通过。

## Popup 性能对照

| 指标 | 本轮前 | 最终版本 |
| --- | ---: | ---: |
| 宽度 | 360px | 340px |
| 首屏高度 | 505px | 438px |
| 首屏 DOM 节点 | 175 | 140 |
| 实际解析脚本字节 | 1025235 | 1018882 |
| 七次打开首帧中位数 | 53.8ms | 54.0ms |
| 冷后台首次可操作 | 191.0ms | 196.4ms |

两次均确认停止后台 worker 后再采样，未挂载隐藏语言选项，无长任务或全页 TreeWalker。首帧中位数基本持平；单次冷启动有正常波动，不据此宣称启动提速。最终七次采样与交互检查均通过。
