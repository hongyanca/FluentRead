# Google Drive 同步修复验证

2026-10-03。基于最新 main 整合 PR #303，保留已发布的中英文隐私政策；原 PR 分支不修改。

## 修复结果

- 服务选择和连接定义、路由模型、凭据一起合并，防止选择已删除的自定义服务。确认时先校验最终完整配置及引用关系，再允许任何云端写入。
- 预览按设置页签和客户端绑定；其他页面不能取消、确认或替换当前预览。页面关闭、预览过期、同步失败或完成后清理相应事务和授权缓存。
- 配置 JSON 上限 20 MiB，云端密文上限 32 MiB；预览元数据单独预留 1 MiB。云端文件和基线不重复加密封装。保留旧加密文件格式兼容性。
- 普通开关、延迟、容量等设置显示名称和值，连接摘要只含内置服务 ID 和自定义服务数量；密钥、URL、请求体、请求头、未知字段仍隐藏。
- 同步反馈、HTTP 状态、冲突标签及连接摘要覆盖七种界面语言；时间按所选界面语言格式化。语言资源按语言拆分并更新 userscript 资源；最终 userscript 为 1,901,442 字节，低于现有 1,950,000 字节预算。
- 小屏预览限定在视口内，内容滚动，取消与确认按钮保持可见；忙碌时禁用重复确认。

## 证据与边界

53 个同步专项用例覆盖授权、API、加密、完整配置、预览事务、消息与客户端；同步业务模块 statements、branches、functions、lines 均为 100%。另有 54 个 i18n 契约和 18 个清单契约用例。包含 20 MiB 明文边界加密及解密、6 MiB 自定义请求体首次上传后再次同步、后台重启后的合并与另一设备恢复。账号、API、存储使用虚构夹具；加密使用真实 Web Crypto。

浏览器使用后台 Codex IAB 页签、真实 Vue 组件、Element Plus 和项目 i18n 插件，后台响应为虚构夹具。检查英文冲突名称和值、未解决冲突时禁用确认、解决后可确认、成功收起预览、英文网络错误与重试、中文首次上传方向、首次恢复必须选择方向、下载覆盖确认及返回预览、取消及控制台。390 × 844 视口下页面 scrollWidth=390，弹窗宽 366，顶边 16，底边约 797，确认按钮底边约 781，无横向溢出；恢复默认视口后结束。

验证范围包括类型检查、测试审计、Chrome / Firefox 构建、userscript 构建与 verifier、文档构建。没有执行仓库全量回归；没有使用真实 Google 账号上传用户凭据或实际跨设备恢复。合并代码与商店发布是不同步骤，正式发行前仍应使用发布扩展完成真实账号同步验证。
