# 学习中心：明确学习与复习入口

2026-10-06，基于生产扩展进行针对性验证。本轮沿用 FluentRead 的 Vue、领域模型、后台消息和复习调度，没有借鉴或修改参考仓库。

## 页面与产品行为

- 三个栏目保持「单词与句子 / 阅读记录 / 学习笔记」，顶部使用轻量导航；本地保存期限与备份入口集中在共用页脚。
- 收藏列表把数量与主操作「复习 N 条」放在一起，收藏开关、再次遇见、导入导出及清空归入「管理收藏」。
- 搜索与类型选择合为一行，掌握状态和排序按需展开。无结果时可以清除全部筛选，不必逐个寻找被设置的条件。
- 每条收藏直接显示「学习用法」或「听读与理解」。打开学习页只读取已有内容，不自动请求 AI、不修改掌握状态。旧收藏与新收藏统一采用领域的句子识别规则，完整句子译文直接展示。
- 复习先回忆，再揭晓，只有用户明确选择「记得 / 忘了」才更新计划。当前列表筛选不改变本轮到期复习范围，每轮最多 20 条；揭晓后去除重复的原文与来源句。
- 学习笔记的回答参考与容量说明收进折叠区域，仍可随时保存和编辑笔记。

## 验证结果与边界

21 项真实 Edge 专项通过，无页面未处理异常；临时独立 profile、后台可见窗口完整位于第二块显示器，`launchMode=macos-background-cdp`、`focusPolicy=launchservices-no-foreground`、`browserFrontmost=false`。测试完成后关闭该实例并删除其临时 profile。

覆盖生产 popup/options 入口、收藏按钮状态在重开后的持久化、关闭收藏入口后保留数据、句子与表达学习入口、翻译文本搜索、类型与掌握筛选、清除筛选、主动回忆评分持久化、1024/390 像素布局、七种界面语言的窄屏操作边界、深色页面，并回归切换标签及音频启停时的卡片位置稳定性。后台配置协议未变，本轮没有新增快速关闭或乱序保存专项。

五个直接相关生命周期与组件文件共 34 项通过。国际化契约 54 项通过，另有 3 项既有失败：漫画缓存说明的缺失译文、已移除 Google/Lingva 接口的旧反馈、已移除供应商与邮箱设置的五条旧校正文案。本轮替换的旧文案已移除，没有增加新的缺失项。

TypeScript/Vue 检查、Chrome/Firefox 构建、userscript 构建与 verifier、测试审计通过。Firefox 仅构建，没有据此宣称 Firefox 交互通过。翻译和 AI 使用本地确定性夹具；音频使用静音 WAV，不代表真实模型输出或实际听感。打开设置消息与目标栏目的验证是真实链路，原生创建页签改为更新预创建后台页以保护焦点。本轮为针对性回归，没有运行全量回归。
