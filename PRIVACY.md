# FluentRead privacy policy

FluentRead is an open-source browser extension for bilingual translation and reading assistance. The complete policy is maintained with the user documentation:

- [English policy in this repository](./docs/en/guide/privacy.md) · [Published website](https://read.thinkstu.com/en/guide/privacy)
- [简体中文隐私政策](./docs/guide/privacy.md) · [官网版本](https://read.thinkstu.com/guide/privacy)

The policy explains translation requests, service credentials, local records and retention, optional Google Drive configuration sync, public-passphrase encryption limitations, and how to revoke access or delete data. The Google Drive feature is currently in Chrome testing; this document does not imply that all store versions include it. GitHub Pages publishes the website from `docs` through the documentation deployment workflow.

FluentRead's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including applicable Limited Use requirements. Google data is used for configuration sync and restoration, not advertising, general-purpose AI training, or unrelated content generation.

For privacy or deletion questions, contact the maintainers through [GitHub Issues](https://github.com/FluentRead/FluentRead/issues) or [email](mailto:a1914493943@gmail.com). Do not post credentials or private content in public reports.
